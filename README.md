# 직업 대전 - NEON CITY REMASTERED

## OFFLINE
- **[ P1 ]** 
    - 이동: `WASD` (`W`: 점프, `S`: 가드)
    - 조작: `J` (약), `K` (강), `L` (스킬)
- **[ P2 ]** 
    - 이동: 방향키 (`↑`: 점프, `↓`: 가드)
    - 조작: `NUM1` (약), `NUM2` (강), `NUM3` (스킬)
- **[ ESC ]** 일시정지 메뉴
